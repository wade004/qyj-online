# QYZ-Belief-CFR 德州扑克机器人设计

## 目标与当前状态

目标是在《群英决》的 12 手牌、升盲、英雄技能和最高 9 人牌桌中，建立一个可训练、可评测的强机器人体系。当前产品启用 6/9 人桌，策略与范围内核覆盖 2–9 人。

当前代码交付的是第一阶段的在线强基线：严格信息集、完整行动历史、每位对手 1326 组合范围、贝叶斯更新、多人无重复联合采样、范围权益/边池份额、位置与筹码策略、混合行动和技能信息约束。它相较原先“均匀随机对手暗牌 + 固定阈值”有本质提升，但尚未经过完整 QYZ 自博弈训练，因此不能把当前版本宣称为已经达到世界顶尖职业牌手水平。

第二阶段的训练—评测闭环也已经落地：v2 固定长度公共历史抽象、合法动作/加注权隔离、无技能单手 external-sampling MCCFR、多人数/回合/筹码覆盖课程、确定性 checkpoint 保存/恢复、因果 Bernoulli 干预，以及固定牌序、座位轮换、镜像桌序、候选/基线逻辑槽位交叉、cluster bootstrap 置信区间和自动晋级门。当前训练树仍是单手、有限加注抽象，不是完整 12 手全技能 QYZ；checkpoint 只有同时通过覆盖、平均影响、动作改变率和独立联赛置信下界门槛后才允许晋级，未通过时线上机器人继续使用原范围/EV策略。

## 2017 论文的正确定位

《基于手牌预测的多人无限注德州扑克博弈方法》最值得保留的是以下流水线：

```text
行为理解 -> 对手建模 -> 未知手牌范围 -> 范围加权蒙特卡洛 -> 决策
```

本项目保留这条骨架，但替换了论文中已经过时或不严谨的部分：

- 不再“每街只保留最激进行动”，而是保存逐动作、逐街、跨手的完整历史；
- 不采用手工的胜率匹配区间，而是用位置、人数、下注比例、SPR、牌面、听牌、阻断牌和收缩后的 HUD 数据构造动作似然；
- 不把各对手独立发牌，而从条件联合分布中抽取互不冲突的物理暗牌；
- 平局按实际份额累计，并按主池/边池资格计算期望回收额；
- 不用单一胜率阈值直接决策，而比较跟注、下注、加注和全下的近似 EV，并在接近 EV 的动作间混合；
- 多人底池抑制纯诈唬、提高坚果潜力要求，并区分是否关闭行动；
- 私有技能结果严格按座位隔离，未来牌和窥牌作为条件信息进入模拟。

## 在线信息集

机器人只能获得：

- 自己的两张暗牌；
- 已揭示的公共牌；
- 公开筹码、底池、下注、座位、英雄、能量和技能状态；
- 完整公开行动历史；
- 该座位通过技能合法得到的私有结果；
- 当前合法扑克动作。

机器人不能获得牌堆、对手暗牌、尚未揭示的公共牌或其他座位的私有技能结果。

## 对手范围

每名对手维护全部 1326 个物理两牌组合的对数权重。观察到动作后：

\[
\log w_{t+1}^{(j)}(h)=
\log w_t^{(j)}(h)+
\log\max\left(\epsilon,
P(a_t\mid h,I_t,\theta_j)\right)
\]

其中 `I_t` 包含街道、位置、人数、底池、跟注额、下注比例、SPR、牌面和此前加注次数；`θ_j` 是经过小样本收缩的 VPIP、PFR、3-bet、AF 和弃牌倾向。

陌生玩家从总体基线开始。QYZ 只有 12 手牌，因此对本场临时统计只给予较低可信度，避免根据两三个异常动作做激进 exploit。

### 技能证据

- 窥见一张对手暗牌：目标范围必须包含该物理牌，并从其他范围排除；
- 对手公开一张暗牌：对所有观察者应用同样硬约束；
- 得知强度区间：作为带噪声的软似然，而不是硬删除组合；
- 得知下一张公共牌：固定对应牌槽，并从所有对手范围排除；
- 只得知下一张花色：把该花色牌与所有对手暗牌一起做联合条件采样。

## 多人联合发牌

活跃与已弃牌玩家的未知暗牌都属于牌堆阻断。目标分布为：

\[
P(h_1,\ldots,h_q\mid K,E)\propto
\mathbf 1[\text{所有物理牌互斥且满足技能约束}]
\prod_{j=1}^{q} w_j(h_j)
\]

采样器先对所有范围独立提议；一旦任意物理牌冲突，拒绝整组提议。小型窄范围树会完整枚举合法联合分配并按乘积质量抽样，避免“先抽哪个玩家就偏向哪个玩家”的顺序偏差。极端大树才使用带交换提议的稀有后备路径。

已弃牌玩家不参与比牌，但其范围仍被抽取并从剩余牌堆移除。

## 权益与边池

每次模拟：

1. 联合抽取所有未知暗牌；
2. 按技能约束补齐公共牌；
3. 对所有活跃玩家评估七张牌；
4. 平局按赢家人数分摊；
5. 按每人的 `betRound` 逐层构造主池和边池，计算本机器人在每层的期望回收额。

输出包括联合权益、胜/平/负率、标准误差、样本量和按边池资格计算的 `expectedPayout`。例如短码坚果锁定主池时，机器人即使无法“击败所有人”，仍可能因能赢深码边池而正确跟注。加注评估还会把已全下玩家与仍可行动的深码范围分开：既计算所有可行动玩家弃牌后的分层回收额，也只针对能够匹配新增筹码的对手估计新增边池权益，避免主池必败时漏掉正确的边池价值加注。

## 运行时策略

### 翻前

- 以 1326 物理组合标定起手牌百分位；
- 使用 2–9 人精确位置、身后人数、有效筹码、底池赔率、limper、raise/3-bet 次数；
- 默认非小盲不 open-limp；
- 短码推入边界限制在约 12BB 内，并同时检查范围权益和风险成本；
- UTG 到 BTN 的开池范围单调放宽，8–9 人前位更紧；
- 接近边界的组合采用混合频率，不输出完全可预测的固定脚本。

### 翻后

- 跟注用范围条件化权益、底池赔率、是否关闭行动和分层边池回收额；
- 下注/加注估计全员弃牌率、仍可行动的预计跟注者、下注成本和摊牌价值；
- 已全下玩家永远不能被计入弃牌收益，也不能被虚构为继续补筹码；
- 多人联合权益已经包含人数影响，策略层只增加小幅实现率/风险缓冲，不重复线性惩罚；
- 多人局停止范围下注，纯诈唬主要限于单挑；半诈唬要求足够 outs，拥挤底池额外要求坚果潜力；
- 听牌 outs 通过枚举剩余物理牌计算，公共牌自身成顺不算作机器人听牌。

### 12 手牌风险

当前使用轻量的后期排名风险修正：后半程领先者减少边缘高波动投入，短码适度放宽。最终世界级版本必须直接学习：

\[
Q(s,a)=\mathbb E[U(\text{第12手排名、存活、HP、能量})\mid s,a]
\]

而不是仅优化当前一手 chip EV。

## 世界级版本的离线训练路线

运行时范围/EV 层只是强基线。目前已经有可复现、可恢复的抽象 MCCFR 启动蓝图；完整战略底座应继续实现：

1. 把当前单手无技能 MCCFR 适配器扩展到 QYZ 完整 12 手规则；
2. episode 覆盖完整 12 手牌、升盲、全部英雄和技能能量；
3. 用共享玩家编码器与 attention/DeepSets 支持可变 2–9 人，并使用缺席/弃牌/全下 mask；
4. 训练公共信念状态的反事实价值网络和策略网络；
5. 实战时从当前街开始进行动态深度 CFR，叶节点由价值网络估值；
6. 玩家画像只作为有可信度上限的 exploit 覆盖层，主体保持自博弈蓝图；
7. 后续可加入 EVPA 的期望值剪枝和动态信息抽象，缩短在线求解时间。

技能必须成为搜索树中的正式动作；其价值由当前信息收益、能量成本、未来手数和后续技能机会共同决定，不能永久停留在“先启发式决定技能，再单独下注”的结构。

当前训练管线已经增加真实 reach 画像驱动的公共子局 MCCFR：它能从生产 Observation 精确重建 2～9 人公共根，并记录每个动作的均值/方差；运行时只有相对当前 QYZ 分布的经验优势 95% 下界为正才允许混合。隐藏牌 chance sampling 已升级为温度化公共信念范围：重放公开行动后，从最多八个对手的 1326 组合后验中联合无冲突采牌，弃牌者仍阻断 runout；独立 held-out log-loss/Brier 均优于 uniform。该能力解决了“训练节点没有真实到达”“公开行动后仍均匀发牌”和“策略表命中却可能更差”三类工程问题，但独立联赛仍显示有效接管过少，尚未形成强于 QYZ 的可部署模型。下一阶段应把单手 chip EV 叶值升级为带 OOD 回退的完整 12 手牌公共价值模型，而不是放宽安全门。

## 强度验证门槛

- 2、3、4、6、9 人分别报告结果；
- 固定随机种子、同牌序交叉对局、轮换所有座位；
- 报告最终排名效用、存活率、筹码 EV、边池 EV 和置信区间；
- 单挑兼容模式接入公开 HUNL 基准；
- 多人使用 Local Best Response、历史 checkpoint 联赛和多类型对抗策略池；
- QYZ 真人测试必须让职业牌手先熟悉全部英雄技能；
- 未通过大样本职业牌手盲测前，不使用“已达到世界顶尖”宣传语。

## 主要实现文件

- `js/game/observation.js`：严格信息集投影；
- `js/game/engine.js`：动作历史、技能知识和动态桌型；
- `js/game/opponent-range.js`：1326 组合范围、动作似然、联合采样；
- `js/game/winrate.js`：范围权益、技能牌槽和边池回收；
- `js/game/ai-policy.js`：2–9 人纯策略/EV与混合策略；
- `js/game/ai.js`：状态同步、技能使用和 Engine 适配；
- `js/game/blueprint-policy.js`：v2 定长信息集、严格 checkpoint 校验、经验优势下界和因果 Bernoulli 干预；
- `training/blueprint/target-profile.js` 与 `training/blueprint/targeted.js`：隐私受限的真实 reach 画像、精确公共根重建和目标子局训练；
- `training/train-blueprint-targeted.mjs` 与 `training/publish-blueprint-backoff.mjs`：高频 exact 训练和带支持下限的分层发布；
- `training/blueprint/`、`training/train-blueprint.mjs` 与 `training/train-blueprint-curriculum.mjs`：可恢复 MCCFR、无技能抽象牌局和覆盖课程；
- `training/eval/` 与 `scripts/run-ai-league.mjs`：镜像联赛、cluster 置信区间和自动晋级门；
- `test/observation.mjs`、`test/opponent-range.mjs`、`test/ai_advanced.mjs`：泄密、概率、九人桌、边池和合法动作回归。
