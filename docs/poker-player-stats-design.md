# 玩家扑克倾向统计设计

## 1. 产品目标

玩家统计用于帮助用户理解对手的公开行动倾向，不直接给出“跟注/弃牌/加注”等实时决策建议。
统计只来自本游戏服务端已经公开广播的行动，不保存或推断暗牌，也不导入第三方牌局数据。

参考产品与口径：

- [PokerTracker Statistical Reference Guide](https://www.pokertracker.com/guides/PT3/general/statistical-reference-guide)：
  3Bet 必须使用“发生次数 / 有效机会次数”，AF 为下注与加注次数除以跟注次数。
- [GGPoker Smart HUD](https://ggpoker.com/blog/your-strategy-guide-to-ggpokers-smart-hud/)：
  桌面核心展示 VPIP、PFR、3Bet、ATS 与手数，点击头像后再展示 CBet、Fold CBet、WTSD、W$SD 和总激进频率。
- [Hand2Note HUD Manual](https://hand2note3.hand2note.com/Help/pages/HUDOverview/)：
  常驻 HUD 应保持少量静态指标，更细的统计放在点击展开层。
- [PokerStars Third Party Tools Policy](https://www.pokerstars.com/poker/room/prohibited/)：
  数字统计与实时行动建议之间需要明确边界；本项目不根据当前牌面自动切换指标或输出操作建议。

## 2. 默认统计范围

默认范围固定为 **近 30 天、最多最近 200 手**。

- 30 天保证数据能反映近期打法，而不是被很久以前的策略长期稀释。
- 200 手限制数据库查询量，也避免界面让旧样本产生虚假的精确感。
- 所有比率旁必须展示实际手数和样本可信度。

可信度：

| 有效手数 | 标识 | 含义 |
|---:|---|---|
| 0 | `none` | 暂无样本 |
| 1–29 | `low` | 样本较少，仅作初步观察 |
| 30–99 | `medium` | 有一定参考价值 |
| 100–200 | `high` | 在当前窗口内相对稳定 |

## 3. 指标与公式

| 指标 | 中文 | 公式/口径 |
|---|---|---|
| Hands | 手牌样本 | 窗口内实际参与并获发暗令的手数 |
| VPIP | 主动入池率 | 翻牌前除盲注外主动跟注、加注或有效全下的手数 / 总手数 |
| PFR | 翻牌前加注率 | 翻牌前至少一次有效加注的手数 / 总手数 |
| 3Bet | 再加注率 | 面对首次翻牌前加注时再加注的次数 / 有效 3Bet 机会次数 |
| AF | 翻牌后激进度 | 翻牌后下注或加注次数 / 翻牌后跟注次数；没有跟注分母时显示 `—` |
| WTSD | 摊牌率 | 看到翻牌后最终进入摊牌的手数 / 看到翻牌的手数 |
| W$SD | 摊牌胜率 | 摊牌时赢得至少一个池的手数 / 摊牌手数 |
| CBet | 翻牌持续下注率 | 翻牌前最后加注者在翻牌获得持续下注机会并下注的次数 / CBet 机会次数 |
| Fold CBet | 面对持续下注弃牌率 | 面对翻牌持续下注后弃牌次数 / 面对 CBet 的有效机会次数 |

## 4. 信息层级

- PC 对局头像悬停/聚焦后显示迷你 HUD：`VPIP / PFR / 3Bet / AF / Hands`；点击或键盘打开详情。
- H5 对局：不常驻密集数字；点击武将立牌打开统计抽屉。
- 大厅与房间：玩家卡提供“查看数据”入口。
- 详情面板：补充 WTSD、W$SD、CBet、Fold CBet、范围和样本可信度，并给出中性释义。

## 5. 数据与公平性

- SQLite 只保存公开行动派生的布尔标记和计数，不保存暗令。
- 客户端只能读取服务端统一下发的聚合值，不能传入或篡改统计。
- 所有玩家在同一房间看到相同口径；不展示自动玩家类型标签，不输出针对当前行动的建议。
- `(match_id, round, player_id)` 唯一，断线恢复、重复结算和服务重启不会重复累计。
